# matchday-tracker

A Python command-line app for tracking soccer match performances and basic stats.

---

## Features

- Add a match performance
- Save match data to a CSV file
- View all recorded matches
- Show total goals, assists, and matches
- Show average goals and assists per match
- Show win/loss/draw record
- Basic input validation

---

## Tech Used

- Python
- CSV file handling
- Command-line interface

---

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/aliakhtar1010/matchday-tracker.git
```

2. Go into the project folder:

```bash
cd matchday-tracker
```

3. Run the program:

```bash
python matchday_tracker.py
```

## Why I Built This

I built this project to practice Python fundamentals, file handling, functions, loops, conditionals, and working with CSV data through a soccer-related project.
